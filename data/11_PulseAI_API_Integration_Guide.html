2. Authentication

Use OAuth 2.0 client credentials. Send Authorization: Bearer <access_token>, Content-Type: application/json, and a unique Idempotency-Key for retryable POST requests. Tokens are tenant- and region-bound and normally expire after 60 minutes.

POST /oauth2/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials&client_id=CLIENT_ID&client_secret=CLIENT_SECRET&scope=reports:write reports:read

3. Create a Forecast Job

POST /forecast-jobs
{
  "model_id": "demand-forecast-v3",
  "dataset_id": "ds_7f49c2",
  "horizon": {"unit": "day", "value": 30},
  "confidence_intervals": [0.80, 0.95],
  "output": {"format": "json"}
}

Successful requests return 202 Accepted with a job ID and status URL. A job is complete only when status is succeeded.

7. Webhooks

PulseAI signs callbacks with HMAC-SHA256 in X-PulseAI-Signature. Verify the raw request body and timestamp. Reject callbacks older than five minutes. Respond within 10 seconds; failed deliveries are retried for 24 hours.

8. Security and Data Handling

Never place client secrets in browser code, mobile apps, source repositories, Jira, or Slack. Use an approved secrets manager and rotate credentials immediately after suspected exposure.

9. Support

Provide environment, tenant ID, endpoint, timestamp, HTTP status, and correlation ID. Do not attach raw customer data unless Support provides an approved secure-upload path.
