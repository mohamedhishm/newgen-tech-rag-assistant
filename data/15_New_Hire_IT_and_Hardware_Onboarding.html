New Hire IT and Hardware Onboarding

Procedure: NGT-IT-015 | Owner: Internal IT | Target: Day-one readiness

1. Before Start Date

Hiring manager submits the onboarding request at least seven business days before start. Required fields: legal name, preferred display name, role, manager, department, start date, work location, required systems, repository teams, customer access, and hardware profile.
TimingIT action
T-7 business daysCreate identity record, reserve license, select device, start access approvals
T-3Enroll laptop in device management, patch, encrypt, test VPN and security tools
T-1Send manager the handoff status; send employee pickup or courier instructions
Day 1Verify identity, deliver temporary activation path, complete 2FA and device check

2. Standard Hardware

Engineering and data roles receive a supported developer laptop profile; business roles receive the standard productivity profile. Exceptions for memory, GPU, accessibility, operating system, or customer tooling require manager and IT approval. All laptops use full-disk encryption, endpoint protection, screen lock, and managed patching.

3. Account Setup

  1. Activate company identity using the time-limited invitation.
  2. Register Microsoft Authenticator or an approved hardware security key.
  3. Store recovery codes in the approved password manager, never in email or Slack.
  4. Enroll the laptop and confirm compliance.
  5. Connect to VPN and change the initial password.

4. Mandatory 2FA

2FA is required for Microsoft 365, Slack SSO, Jira/Confluence, GitHub, VPN, cloud consoles, and production-support systems. SMS is a fallback only where no supported stronger method exists.

5. Baseline Access

SystemProvisioning rule
SlackCompany workspace, department channels, onboarding channels

GitHubEngineering roles only; team-based repository access
VPNRole-appropriate network profile after compliant-device check
AWS/GCP/ProductionNot baseline; separate least-privilege approval and training

6. Day-One Verification

  • Laptop boots, encrypts, patches, and reports compliant.
  • Email, calendar, Slack, and service portal work.
  • 2FA and password manager are configured.
  • VPN works from the employee's location.
  • Manager confirms role-specific group membership.
  • Employee completes security-awareness assignment.

7. Prohibited Actions

Do not share temporary credentials, install unapproved software, disable endpoint controls, connect personal storage, or request another employee's access profile as a shortcut.

8. Support

Open an IT Helpdesk ticket with device asset tag, screenshot without sensitive data, time, and error. Suspected compromise must be reported immediately through the security incident channel.
